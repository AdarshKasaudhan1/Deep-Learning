Conclusion

In this experiment, we calculated Mean Squared Error and Cross-Entropy Loss using Python. We compared their values using actual class labels and predicted probabilities.

We learned that MSE measures squared differences, while cross-entropy measures how well predicted probabilities match the correct labels. Both are useful for measuring prediction errors, but cross-entropy is generally more suitable for classification tasks.
