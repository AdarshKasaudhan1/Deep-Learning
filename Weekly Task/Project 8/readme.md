In this project, I implemented Gradient Descent using a simple dataset. The model started with a weight and bias of zero and updated them during each iteration.

As training progressed, the loss decreased, showing that the model was improving its predictions. This helped me understand how Gradient Descent updates model parameters to reduce prediction error.

Result

Gradient Descent was successfully implemented, and the loss decreased over multiple iterations. The model learned parameter values close to the expected linear relationship.
