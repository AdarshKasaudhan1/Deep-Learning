In this project, I trained and compared a neural network using SGD and Adam optimizers on the Iris dataset.

Both optimizers helped the model learn, but Adam performed better in this experiment. It achieved higher test accuracy and lower test loss than SGD.

This comparison helped me understand how different optimizers update neural network parameters and how their performance can vary during training.

Result

The neural network was successfully trained using SGD and Adam. Based on the recorded test results, Adam achieved better performance than SGD in this experiment.
