CNN Architecture and it's comparison 
A basic Feedforward Neural Network (FNN) works well for simple structured data, but it is not 
efficient when the input is a large image, because it does not understand spatial patterns like edges 
or shapes. This is where Convolutional Neural Networks (CNN) come in, since they are specially 
designed to scan images and pick out visual features. Similarly, when the data comes in a sequence, 
like a sentence, speech, or stock prices changing over time, we need a network that can remember 
previous information. This is exactly what a Recurrent Neural Network (RNN) is built for, since 
it has a kind of memory that carries information from one step to the next.
This is why in real-world applications, choosing the right deep learning architecture for the right 
type of problem is very important. In this project, we will study FNN, CNN, and RNN in detail, 
understand their working, compare them, and look at where each of them is applied in daily life.
